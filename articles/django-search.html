Realizando buscas em registros com Django

Artigo Técnico | Django

Nesse artigo irei mostrar um passo à passo de como realizar uma busca de registros e listar no banco de dados.

1. Ferramentas.

Usarei o banco de dados SQLite que ja vem configurado como padrão no django e facilitará nosso entendimento, deixando essa explicação mais rapida;

Usarei, também, o editor de texto Visual Studio Code, mas nesse caso você poderá usar o editor do seu gosto.

OBS: Lembrando que eu darei foco ao sistema de buscas e não à questão de inserção de dados no banco, o exemplo que verás aqui será com registros ja inseridos no banco de dados, trarei somente a estrutura da base de dados.

2. Iniciando o projeto:

Tendo como base de que você ja instalou o django e configurou o ambiente virtual, inicie sua APP e seu PROJETO da seguinte forma:

Para iniciar o projeto: django-admin manage.py startproject config .

Para iniciar a app: django-admin manage.py startapp core

Obs: Dei o nome do meu projeto de config (ja que as configurações da aplicação se localiza naquele diretório);

Dei o nome na minha app de core, para representar a app principal da aplicação.

Utilizei o um “ponto final” logo após o nome do meu projeto para que, o django não crie subpasta no direitorio de configuração do projeto.
