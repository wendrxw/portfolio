Envio de E-mail com Python-smtplib

Artigo Técnico | Python

Hoje em dia, qualquer sistema que se diga “bom”, precisa no minimo ter um mecamisno para envio de e-mail. Pensando dessa forma, venho lhes trazer um passo à passo para trabalhar com envio de e-mail com python, usando a biblitoeca “smtplib”.

Como vamos usar uma biblioteca padrão do python, não precisaremos instalar nada, apenas importar a biblioteca para o nosso projeto. Sendo assim, podemos dar inicio.

Crie um arquivo “.py” para escrever nosso codigo, no meu caso criei um arquivo chamado “app.py”. Após isso, importe a biblioteca “smtplib”, da seguinte forma:

  • Import smtplib

Percebe-se que no comentário da imagem àcima digo que, iremos trabalhar de forma estática, ou seja, os dados de remetente e destinatário estarão fixados no codigo, ao invés de recebermos ele dinamicamente de um formulário (ja que não usaremos interface web, somente python puro).

Nesse artigo usaremos o bloco de teste “try” & “except”, para trabalhar com possiveis erros e manipula-los caso ocorram.

Basicamente,:

- O bloco “try” permite testar um bloco de código para erros;

- O bloco “except” permite lidar com o erro.
